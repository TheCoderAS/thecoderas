04July 2026Built end to end

Rebuilt a live e-invoicing gateway, with no downtime

A live service that files invoices with Singapore, Malaysia and Philippine tax systems needed rebuilding on a new technology stack. It was in daily use, so it couldn't go down or change its answers.

How I know it works
  • Old and new services gave identical output on real requests
  • Handles all production e-invoicing since the switch
  • About 970 automated tests

What I built

  • The full service, from data to public API
  • Support for each country's tax system
  • Background processing for submissions
  • Release checks and production monitoring

Hardest part

Proving the new service behaved exactly like the old one. I ran both side by side on real traffic and compared every answer. That surfaced two small differences no test had found. Once both matched perfectly, I switched over.

Made stronger along the way

Reliable by design

Every update is recorded, backed by tests.

Resilient to slow providers

Documents keep moving even when a provider is slow to reply.
